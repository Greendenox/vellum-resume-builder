Where is my resume saved?

Vellum stores your resume locally in the app on this device using browser storage. There is no Vellum account or cloud database. Use File menu → Export JSON backup to save a portable copy, and Clear all local data to remove everything.

How do I export a PDF?

Click Export PDF in the preview toolbar (or press Ctrl+P). In the Windows print dialog choose Microsoft Print to PDF or Save as PDF. Vellum supplies a Letter-size print stylesheet automatically.

How does the ATS score work?

Vellum simulates six signals: role-keyword coverage, quantified impact, writing quality, contact completeness, section structure, and template parseability. It is a practical guide, not a guarantee. Recruiters and ATS vendors use different rules. Aim for 85+ and always tailor the content to the specific role.

How do I use the Pro trial?

Open Upgrade to Pro and start the 7-day trial. This preview build also accepts the demo code VELLUM-DEMO. No payment is collected in the preview. Role Studio unlocks after Pro is active.

Why can’t Vellum read a job URL?

Some job boards block external readers or require a login. Paste the description directly into Role Studio instead. For a job board with many listings, open the exact role first — importing a whole board produces weaker keyword matches.

Can I move my resume to another device?

Yes. Use File menu → Export JSON backup on the old device and Import JSON backup on the new one. Your templates, sections, and target role are included.

Vellum is a local-first app. We cannot recover a resume that was deleted from local storage and never exported. Export a backup before clearing device data.
